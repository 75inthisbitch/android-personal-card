# Android Personal Card

A collection of simple Android applications built with Kotlin and Jetpack Compose.

The repository contains small projects demonstrating Kotlin fundamentals and the creation of Android user interfaces.

## Projects

### Stage 1 – Kotlin basics
A simple Kotlin program that displays personal information and calculates the total number of hours from weekly hours and the number of weeks.

### Stage 2 – Class information
An Android app presenting basic information in a clean layout using Jetpack Compose text components.

### Stage 3 – Interests
An Android screen presenting interests and skills, with an image and a layout built using Compose components.

### Stage 4 – Personal card
A personal business card featuring an avatar, a short introduction and sample contact details.

## Technologies

- Kotlin
- Android Studio
- Jetpack Compose
- Gradle

## Running the apps

1. Open the selected stage folder in Android Studio.
2. Wait for Gradle sync to finish.
3. Start an Android emulator or connect an Android device.
4. Run the app using the **Run** button.

Stage 1 is a standalone Kotlin program and can be run in IntelliJ IDEA or Kotlin Playground.

## Repository structure

- `etap-1/` – Kotlin basics
- `etap-2/` – first Android screen
- `etap-3/` – images and Compose layouts
- `etap-4/` – personal business card
- `screenshots/` – application screenshots

## Customization

The sample name, school details, interests and contact information can be changed directly in the source code. Replace the sample avatar or other drawable resources with your own images if needed.
